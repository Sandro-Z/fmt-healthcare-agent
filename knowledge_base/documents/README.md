# WGS.FMT 知识库

## 目录结构

- `species/` - 物种数据库：各菌种的详细资料、功能特性、健康意义
- `pathways/` - 代谢通路：各类代谢通路的详细说明和健康关联
- `metabolites/` - 代谢物：肠道代谢物的功能、参考范围、临床意义
- `diseases/` - 疾病关联：菌群-疾病关联的文献证据汇总
- `drugs/` - 药物交互：药物与肠道微生物组交互的研究数据
- `papers/` - 文献摘要：PubMed 等来源的文献摘要
- `general/` - 通用知识：肠道微生物组基础知识、术语解释

## 使用方式

知识库为 Markdown 纯文本格式，支持 grep 快速检索，
由 KnowledgeAgent 根据分析结果自动搜索最相关的知识条目。

## 更新

如需添加新知识条目，请按以下格式创建 .md 文件：

```markdown
# 标题

## 概述
简要描述

## 详细信息
详细内容...

## 相关文献
- [1] PMID: 12345678, 标题, 期刊, 年份
- [2] PMID: 23456789, 标题, 期刊, 年份

## 标签
#标签1 #标签2
```
